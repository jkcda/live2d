# 克隆音色目录

放**参考音频**，用来复刻音色（CosyVoice 2 的零样本克隆）。

## 用法

每个音色两个文件，文件名必须一致：

```
voices/
├── mio.wav     # 参考音频
└── mio.txt     # 这段音频里说的话（逐字转写）
```

然后在应用里把「音色」填成 `mio` 即可。

## 对参考音频的要求

| 项 | 要求 |
|---|---|
| 时长 | **5~15 秒**。太短音色不稳，太长反而变差 |
| 内容 | 自然连续的一段话，**不要有背景音乐** |
| 环境 | 安静，无混响、无底噪 |
| 格式 | wav / mp3 都行，服务会重采样到 16kHz 单声道 |
| 文本 | `.txt` 必须和音频**逐字对应**，包括语气词。对不上会直接影响相似度 |

## 为什么必须要那个 .txt

零样本克隆的原理是「给模型一段音频 + 这段音频的文本」，
让它对齐音素和音色。文本错了，对齐就错了，出来的音色会飘。

## 注意

`*.wav` 不入库（涉及你自己的声音素材）。只有本 README 会进 git。
